# Portfolio — Ilkhom Shergoziyev

Personal portfolio site of Ilkhom Shergoziyev, Android developer at Telecom Soft (Tashkent, Uzbekistan).

**Live:** https://ilhomsh.github.io/Portfolio/

## Contents

| Path | What it is |
| --- | --- |
| `index.html` | The whole site — one static page, no build step, no dependencies |
| `assets/` | Optimised images used by the page (portrait, app icons, screenshots) |
| `Portfolio/` | Original Notion export: full-size images per project, plus the source CSV |
| `Portfolio 564f...md` | The original Notion Markdown export the site was built from |

## Local preview

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy

GitHub Pages serves `index.html` from the repository root — Settings → Pages → Deploy from branch → `main` / `/ (root)`.
